### 3.5 微信维护页面（7天）

| 阶段 | 内容 | 工作量 |
|------|------|--------|
| 1 | 微信 ClawBot 接入配置 | 1天 |
| 2 | 用户-微信绑定管理界面 | 1天 |
| 3 | OpenClaw 技能开发 | 3天 |
| 4 | 后端 API 扩展 | 1天 |
| 5 | 联调测试 + 上线 | 1天 |

**功能要点**：
- 用户场景：查询待办、查看学校进度、更新任务状态、创建待办、查询风险
- 技术架构：**普通微信公众号** → OpenClaw → 各成员独立 Agent → GX 后端 API
- **微信接入方式**：普通微信公众号（非企业微信），用户标识为 openid
- **绑定流程**：
  1. 用户在系统管理-微信对话页面生成5分钟有效绑定码
  2. 用户关注微信公众号，发送绑定码
  3. 系统验证绑定码，关联 openid 与系统用户
- 需要开发：
  1. 微信公众号接入配置（服务器URL、Token验证）
  2. 用户-微信绑定管理（绑定码生成、绑定关系管理）
  3. OpenClaw 技能开发（待办增删改查、交付查询、风险查询）
  4. 后端 API 扩展（通过 openid 识别用户的认证接口）

**数据库表**：
- `wechat_user_bindings`：user_id, wechat_openid, nickname, avatar_url, status, bound_at
- `wechat_conversations`：user_id, wechat_openid, message_type, user_message, bot_reply, intent, action_result, created_at

### 3.6 智能助手（6.5天）

| 阶段 | 内容 | 工作量 |
|------|------|--------|
| 1 | 知识库管理（上传/切片/向量化） | 2天 |
| 2 | RAG 检索与生成接口开发 | 2天 |
| 3 | 前端对话界面 | 1.5天 |
| 4 | 联调测试 | 1天 |

**功能要点**：
- **三种问答模式**（通过问答路由器智能分发）：
  1. **知识库RAG问答**：检索知识库文档 → 基于检索结果生成答案
  2. **项目数据查询**：自然语言转SQL → 查询数据库 → 自然语言总结
  3. **大模型Agent问答**：调用MiniMax Agent → 工具调用 → 推理分析
- 知识库管理：
  - 支持格式：.md / .pdf / .txt / .docx / .zip（批量）
  - 处理方式：自动切片 → 向量化 → 存入向量库
  - 初期为空，由用户自行上传
- 问答流程：用户提问 → 问答路由器判断类型 → 分发到对应处理器 → 生成回答
- 技术方案：
  - 嵌入模型：text-embedding-ada-002 / bge-large-zh
  - 大模型：MiniMax-M3（已配置）
  - 向量数据库：FAISS（本地）/ Milvus（生产可选）
  - 检索策略：Hybrid Search（向量+关键词）
  - RAG 框架：LangChain

**数据库表**：
- `knowledge_documents`：id, title, content, file_path, category, tags, embedding_status, uploaded_by, created_at
- `qna_conversations`：id, user_id, session_id, question, answer, answer_type, sources, feedback, created_at

**界面要求**：
- 知识库管理：上传文档、管理知识库
- 对话区域：消息列表、输入框、发送按钮

## 八、风险与注意事项

### 8.1 技术风险

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| Word/PPT 导出复杂度高 | 开发周期可能延长 | 预先调研库的能力边界，复杂排版降级为简化版 |
| 向量检索召回率不足 | 问答质量下降 | 采用 Hybrid Search，结合关键词检索提升召回 |
| 微信 ClawBot 配置复杂 | 需要协助配置 | 提前准备文档和测试账号 |

### 8.2 数据风险

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| 知识库文档包含敏感信息 | 泄露风险 | 上传前提示用户检查，支持文档权限控制 |
| 微信绑定后账号安全 | 被冒用风险 | 二次验证机制，敏感操作需确认 |

### 8.3 进度风险

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| P0 功能工作量超预期 | 影响第一期交付 | 优先保证核心功能，次要功能降级或延后 |
| OpenClaw 技能开发依赖外部协助 | 阻塞微信功能 | 提前沟通，准备 API 文档和测试环境 |
