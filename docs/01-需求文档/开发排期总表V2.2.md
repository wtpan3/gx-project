## 五、开发规范（每模块通用）

1. 每模块按「数据模型确认 → 后端 API → 前端页面 → 联调 → L3 浏览器验证」推进。
2. 无数据模型的模块，先出建表 DDL 并与 `models.py` 对齐（防数据不一致）。
3. 每完成一模块做 L3 端到端验证（真实浏览器走完用户路径 + 数据准确性检查）才算完成。
4. 前端新页面替换 `App.tsx` 中对应的 `<Placeholder />` 路由。
