# GX教育项目交付管理系统 - 全局设计

**版本**: V1.2
**日期**: 2026-07-29

## 一、布局规范

### 1.1 整体布局
- 左侧固定侧边栏（宽度220px）
- 右侧滚动内容区
- 顶部导航栏（高度56px）

### 1.2 侧边栏要求
- `position: sticky; top: 0; height: 100vh; overflow-y: auto;`
- 不随主内容区滚动
- 菜单项按顺序排列（见下文）

## 三、数据可下钻（全局交互规范）

**所有列表、统计数字、卡片、图表等数据内容都必须支持下钻**：

| 元素类型                  | 下钻行为       | 目标               |
| ------------------------- | -------------- | ------------------ |
| 统计卡片                  | 点击跳转       | 对应列表页         |
| 环形图扇区                | 点击弹出       | 该状态下的明细列表 |
| 列表行                    | 点击行任意区域 | 详情弹窗（Modal）  |
| 甘特图/风险/待办/里程碑行 | 点击行         | 详情弹窗（Modal）  |

> **详情交互规范**：详情一律用居中弹窗（Modal），不再用右侧抽屉（Drawer）。项目计划、交付进展、风险管理、设备信息均采用居中弹窗。

## 四、表格规范（全局）

- `table-layout:fixed` 强制固定布局，每列固定宽度，不允许内容撑开列宽
- 单元格文本：`white-space:nowrap; overflow:hidden; text-overflow:ellipsis`，超长省略号截断
- 悬停显示完整内容：`title` 属性或 Tooltip
- 表格总宽超容器时，外层容器 `overflow-x:auto` 横向滚动，**不压缩列宽、不换行**

## 五、通用操作规范

- **删除**：二次确认弹窗"确定要删除【记录名】吗？此操作不可恢复"；被引用则提示"该记录已被引用，无法删除"
- **批量操作**：左侧复选框 + 全选；选中后顶部出现批量操作栏；执行前二次确认；结果反馈成功/失败条数
- **列表搜索**：关键词搜索框在左上，高级筛选按钮在右
- **筛选区按钮**：所有列表页筛选区右侧**必须带「🔍查询」和「🔄重置」两个按钮**
