# GX教育项目交付管理系统 - 全局设计

**版本**: V1.1
**日期**: 2026-07-25

## 一、布局规范

### 1.1 整体布局
- 左侧固定侧边栏（宽度220px）
- 右侧滚动内容区
- 顶部导航栏（高度56px）

### 1.2 侧边栏要求
- `position: sticky; top: 0; height: 100vh; overflow-y: auto;`
- 不随主内容区滚动
- 菜单项按顺序排列（见下文）

## 二、菜单顺序（左侧导航栏）

| 序号 | 菜单项 | 说明 |
|------|--------|------|
| 1 | 首页 | 项目概览Dashboard |
| 2 | 项目计划 | WBS任务管理 |
| 3 | 交付进展 | 各学校交付状态；含培训情况、单校全景（原培训管理、学校看板已整合） |
| 4 | 设备信息 | 设备台账 |
| 5 | 风险管理 | 风险列表与跟踪（轻量级模型） |
| 6 | 报告管理 | 周报/月报生成 |
| 7 | 交付材料库 | 文件统一管理 |
| 8 | 项目复盘 | 验收后复盘 |
| 9 | **系统管理** | **置底**（配置类功能） |

系统管理子菜单：用户管理、学校管理、设备字典、供应商管理、模板管理、数据字典维护（含产线等下拉选项）、项目信息管理、AI配置管理、操作日志

## 三、数据可下钻（全局交互规范）

**所有列表、统计数字、卡片、图表等数据内容都必须支持下钻**：

| 元素类型 | 下钻行为 | 目标 |
|----------|----------|------|
| 统计卡片 | 点击跳转 | 对应列表页 |
| 环形图扇区 | 点击弹出 | 该状态下的明细列表 |
| 列表行 | 点击行任意区域 | 详情弹窗（Modal） |
| 甘特图/风险/待办/里程碑行 | 点击行 | 详情弹窗（Modal） |

> **详情交互规范**：详情一律用居中弹窗（Modal），不再用右侧抽屉（Drawer）。项目计划、交付进展、风险管理、设备信息均采用居中弹窗（设备信息原型 CSS 类名/JS 函数名仍沿用 `drawer` 字样，属命名遗留，行为已是居中模态，开发时按 Modal 实现）。

## 四、页面标题

- 浏览器标签页标题：`GX教育项目交付管理系统`
- 使用环境变量 `%REACT_APP_TITLE%`
