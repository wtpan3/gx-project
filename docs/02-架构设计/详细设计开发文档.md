## 〇、使用说明（开发必读）

### 0.1 本文档定位

本文档是**从原型到代码的翻译层**。它把已定稿的 HTML 原型、V2.3 需求文档、架构设计文件整合为可直接开发的规格说明。

**权威边界（开发严格遵守）**：

- **页面交互 + 视觉呈现**（布局、组件长相、点击后的反应、弹窗/表格样式、字段在页面上如何摆放）：以**定稿原型**为唯一真相源，照原型还原。
- **数据模型、字段定义、状态枚举**：以 **V2.3 需求文档 + 数据库设计 V2.2** 为准。
- **业务逻辑（计算规则、联动规则、校验规则、流转条件等）**：**原型中的业务逻辑不作为权威依据**——原型可能写错。业务逻辑一律以 V2.3 需求 + 业务规则说明为准；**凡有疑问、或原型与需求不一致、或需求本身未写清，一律暂缓实现并向项目经理确认，不得擅自按原型或按推测实现。**
- 已发现的冲突/过时点见「附录 A」，已需确认的业务逻辑见「附录 B」，开发按标注执行或先行确认。

## 一、工程约定

> 技术栈详见 [技术架构说明.md](02-架构设计/技术架构说明.md)；API通用约定详见 [README.md](README.md#api接口规范)。

### 1.1 工程约定

- 所有金额/数量为整型或定点，不用浮点
- 日期统一 `yyyy-MM-dd`，时间 `yyyy-MM-dd HH:mm:ss`
- 软删除字段 `is_enabled`（1启用/0停用），被引用数据不物理删除
- 所有增删改操作写 `operation_logs`


## 二、全局 UI 开发规范

> 整体布局、侧边栏、详情弹窗交互、数据下钻规范详见 [全局设计.md](02-架构设计/全局设计.md)。以下为开发特有规范。

### 2.1 表格规范（强制）

- `table-layout:fixed` 强制固定布局，每列固定宽度，不允许内容撑开列宽
- 单元格文本：`white-space:nowrap; overflow:hidden; text-overflow:ellipsis`，超长省略号截断
- 悬停显示完整内容：`title` 属性或 Tooltip
- 表格总宽超容器时，外层容器 `overflow-x:auto` 横向滚动，**不压缩列宽、不换行**
- 首页里程碑/风险表：表头与内容**全部居中**

### 2.2 通用操作规范

- **删除**：二次确认弹窗"确定要删除【记录名】吗？此操作不可恢复"；被引用则提示"该记录已被引用，无法删除"
- **批量操作**（项目计划/设备信息/风险管理列表）：左侧复选框 + 全选；选中后顶部出现批量操作栏（批量更新状态/批量分配责任人/批量删除）；执行前二次确认；结果反馈成功/失败条数
- **列表搜索**：关键词搜索框在左上，高级筛选按钮在右
- **筛选区按钮（全局统一）**：所有列表页筛选区右侧**必须带「🔍查询」和「🔄重置」两个按钮**，筛选条件选择后点"查询"生效、点"重置"清空。
  
  > ⚠️ **原型缺陷修正**：项目计划原型 V2.2 的 `filter-toolbar` 漏了这两个按钮（做成了即时筛选）。开发时**须补上查询/重置按钮**，不照抄原型的无按钮设计。
- **导出**：可选 Excel(.xlsx) 或 CSV，导出当前筛选条件下全部数据（不分页）

## 四、首页（项目概览）

> 原型：首页原型-V2.1.html ｜ 需求：§6.1 ｜ 路由：/dashboard
> ⚠️ 首页原型为纯静态（无 JS），下钻/详情交互按居中 Modal 实现。

### 4.1 页面布局

主内容区自上而下 5 个区域：

1. **顶部卡片区**：7 个统计卡片，外层 `.stat-scroll` 超宽横向滚动
2. **交付进度区**：整体进度条置顶 + 三栏（学校/硬件/软件）
3. **关键里程碑区**：甘特表
4. **项目风险跟踪区**：表格
5. **待办区**：项目待办、我的待办两个并排等宽独立框

### 4.2 组件清单

| 组件              | 类型                 | 用途                          |
| ----------------- | -------------------- | ----------------------------- |
| 统计卡片 ×7       | KPI 卡片             | 规模概览，每卡可下钻          |
| 整体进度条        | 进度条               | 项目整体进度 % + 悬停显示公式 |
| 学校交付进度      | 环形图+图例          | 6 状态分布                    |
| 硬件交付进度      | 环形图+图例          | 5 状态分布                    |
| 软件平台交付进度  | 条形进度列表 ×4      | 各软件模块进度                |
| 关键里程碑        | 甘特表               | L1+L2 任务时间轴              |
| 项目风险跟踪      | 表格                 | 活跃风险 TOP 5                |
| 项目待办/我的待办 | 卡片+列表+筛选按钮组 | 待办展示与操作                |

### 4.3 字段表

**顶部统计卡片（7个）：**

| 卡片     | 数据来源                       | 特殊             |
| -------- | ------------------------------ | ---------------- |
| 覆盖学校 | schools 计数                   |                  |
| 重点学校 | schools.is_key=1               | 值用红色 #ff4d4f |
| 系统总数 | systems 表计数（is_enabled=1） |                  |
| 设备类型 | devices 按 device_name 去重    |                  |
| 产线类型 | production_lines 计数          |                  |
| 外采设备 | devices 筛选 source='三方外采' |                  |
| 硬件总数 | devices 硬件求和 quantity      |                  |

**关键里程碑甘特表**：`阶段(120px) | 任务(180px) | 时间轴(甘特)(剩余宽度) | 计划开始时间(120px) | 计划完成时间(140px) | 状态(100px)`

**项目风险跟踪表**：`风险等级(90px) | 风险描述(180px) | 影响描述(160px) | 应对措施(160px) | 进展说明(160px) | 责任人(120px) | 状态(100px)`

### 4.4 交互规则

- **统计卡片**：点击 → 页面跳转到对应列表页（带筛选参数）
- **整体进度条**：悬停显示公式 `= 已完成末级任务数 / 总末级任务数`
- **环形图扇区**：点击 → 跳转对应模块筛选列表
- **软件进度条**：颜色随状态（已上线绿/测试中橙/开发中蓝）
- **里程碑行**：点击 → 详情 Modal
- **风险行**：点击 → 风险详情 Modal；"查看全部" → 跳转 /risks
- **待办筛选**：本月/本周/今日按钮，**默认本周**，两框独立筛选
- **待办操作**：校园经理在项目待办中**不显示**指定负责人/编辑按钮

### 4.5 数据来源与 API

| 数据                      | 接口                                                         |
| ------------------------- | ------------------------------------------------------------ |
| 顶部卡片+进度+里程碑+风险 | `GET /api/v1/dashboard/overview`                             |
| 待办                      | `GET /api/v1/dashboard/todos?scope=project|mine&range=week|month|today` |

- 里程碑取数：wbs_tasks 中 L1+L2 任务，不限条数，按 plan_start_date 排序
- 风险取数：risks 中 status≠已关闭，TOP 5

### 4.6 业务规则与联动

- **整体进度** = 已完成末级任务数 / 总末级任务数（末级=work_content_l4 非空；无加权）
- **首页健康度**：🟢正常/🟡关注/🔴异常（详见业务规则说明.md §二）
- 里程碑延期判断：当前日期超过计划完成日期且状态≠已完成 → 自动"已延期"

### 4.7 开发验收点

- [ ] 顶部 7 卡片横向滚动不挤压，重点学校值红色，每卡可点击跳转
- [ ] 整体进度条置顶，悬停显示公式
- [ ] 学校/硬件双环形图 + 软件 4 条进度条，颜色随状态
- [ ] 里程碑甘特表：固定列宽、月份刻度在表头、色条按日期定位
- [ ] 风险表带风险等级列、全部居中、TOP 5
- [ ] 待办双框并排、各自筛选默认本周、校园经理无指定/编辑按钮
