# 数据字典使用说明

## 一、数据字典是什么？

数据字典是系统中**集中管理下拉选项和枚举值**的配置模块。它让非技术人员可以维护系统中各种下拉框的选项内容，无需修改代码。

**核心作用**：
- 统一管理所有下拉选项（产线、培训类型、项目状态等）
- 业务人员可自主维护，不依赖开发人员
- 保证系统各处使用相同的标准值
- 支持动态调整选项而不需重新发布系统

---

## 二、核心概念解释

### 1. 字典类型
**含义**：对下拉选项进行分类，表示这组选项用在什么地方。

**示例**：
- `产线` - 用于产品分类（平台产线、科创教育、AI产线等）
- `培训类型` - 用于培训项目分类（线上培训、线下培训、混合培训等）
- `项目状态` - 用于项目进度标识（立项、实施中、已验收等）
- `优先级` - 用于任务优先级（高、中、低）
- `设备类型` - 用于设备分类（硬件、软件、服务等）

### 2. 字典标签（显示文本）
**含义**：用户在界面上看到的文字，给人看的。

**示例**：
```
字典类型：产线
字典标签：平台产线    ← 用户在下拉框中看到这个文字
字典标签：科创教育
字典标签：AI产线
```

### 3. 字典值（内部代码）
**含义**：程序内部使用的唯一标识符，存储到数据库的值，给程序看的。

**示例**：
```
字典标签：平台产线  →  字典值：platform      ← 数据库存储 "platform"
字典标签：科创教育  →  字典值：sci_edu
字典标签：AI产线    →  字典值：ai_product
```

**命名规则**：
- 使用英文或拼音缩写
- 全小写，单词间用下划线连接
- 简短且有意义（如 `platform`, `sci_edu`, `high`, `low`）

### 4. 排序
**含义**：控制下拉框中选项的显示顺序，数字越小越靠前。

**示例**：
```
产线类型下拉框：
排序1：平台产线      ← 显示在第一位
排序2：科创教育      ← 显示在第二位
排序3：AI产线        ← 显示在第三位
```

### 5. 状态
- **启用**：该选项正常显示在下拉框中
- **禁用**：该选项不再显示，但历史数据仍保留（不会影响已使用该值的历史记录）

## 四、维护操作指南

### 1. 新增字典项

**步骤**：
1. 点击"新增字典项"按钮
2. 选择或输入"字典类型"（如"产线"）
3. 填写"字典标签"（用户看到的文字，如"元宇宙产线"）
4. 填写"字典值"（程序使用的代码，如"metaverse"）
5. 设置"排序"（决定显示顺序，如"5"）
6. 选择"状态"（通常选"启用"）
7. 填写"备注"（可选，说明用途）
8. 点击"确定"保存

**注意事项**：
- 字典值不能重复（同一字典类型下）
- 字典值一旦使用，尽量不要修改（会影响历史数据）
- 排序号建议留间隔（1、10、20...便于后续插入）

---

### 2. 编辑字典项

**可修改内容**：
- ✅ 字典标签（不影响数据）
- ✅ 排序（调整显示顺序）
- ✅ 状态（启用/禁用）
- ✅ 备注
- ⚠️ 字典值（慎重，会影响数据关联）

**典型场景**：
- 发现某个选项名称有歧义 → 修改字典标签
- 需要调整选项显示顺序 → 修改排序号
- 某个选项暂时不用 → 状态改为"禁用"

---

### 3. 禁用字典项

**操作**：点击"禁用"按钮

**效果**：
- ✅ 下拉框中不再显示该选项
- ✅ 历史数据仍然保留（已选择该值的记录不受影响）
- ✅ 可随时重新启用

**典型场景**：
- 某条产品线停止运营 → 禁用该产线选项
- 某种培训类型不再开展 → 禁用该类型
- 过渡期保留历史数据但不允许新增 → 禁用而非删除

## 五、最佳实践

### 1. 命名规范

**字典类型命名**：
- 简短明确，2-4个字
- 示例：`产线`、`培训类型`、`项目状态`、`优先级`

**字典值命名**：
- 使用英文或拼音缩写
- 全小写，下划线分隔
- 示例：`platform`、`online`、`high`、`sci_edu`

### 2. 排序设置技巧

- **重要程度排序**：紧急 > 高 > 中 > 低（1、2、3、4）
- **流程顺序排序**：立项 > 需求分析 > 实施中 > 验收（1、2、3、4）
- **预留间隔**：使用 10、20、30 而非 1、2、3（便于中间插入新选项）

### 3. 维护建议

- **避免删除**：尽量使用"禁用"而非删除（保护历史数据）
- **统一标准**：同类选项命名风格保持一致
- **及时更新**：业务变化时及时同步字典配置
- **添加备注**：为不常见的选项添加说明，方便后续维护

## 六、常见问题

### Q1：字典值能修改吗？
**答**：技术上可以修改，但强烈不建议。因为数据库中存储的是字典值（如 `platform`），修改后会导致历史数据关联错误。建议禁用旧值，新增新值。

### Q2：字典类型可以自定义吗？
**答**：可以。根据业务需要新增字典类型，比如新增"地区"类型来管理省市区选项。

### Q3：为什么要分"标签"和"值"？
**答**：
- **标签**：给人看，可以随时调整文字表述，不影响数据
- **值**：给程序看，数据库存储和程序逻辑使用，稳定不变

例如标签从"平台产线"改为"数智平台产线"，数据库中仍存储 `platform`，不影响任何功能。

### Q4：禁用和删除有什么区别？
**答**：
- **禁用**：选项不可见，但历史数据保留，可随时恢复
- **删除**：彻底移除，历史数据可能出现显示异常（如显示空白或错误代码）

建议使用禁用而非删除。

### Q5：排序号重复会怎样？
**答**：排序号相同的选项，按创建时间先后显示，但建议避免重复，保持清晰的排序逻辑。
