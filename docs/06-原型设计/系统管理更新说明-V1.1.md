# 系统管理原型更新说明 V1.1

## 更新时间
2026-07-XX

## 主要更新内容

### 1. 弹窗居中优化 ✅
- 所有弹窗采用Flexbox布局实现垂直水平居中
- 修改了`.modal`样式，使用`display: flex; align-items: center; justify-content: center;`
- 优化了用户体验，弹窗始终在屏幕中央显示

### 2. AI配置功能增强 ✅

#### 2.1 新增模型提供商
- **MiniMax**：支持abab6-chat、abab5.5-chat、abab5-chat模型
- **Anthropic Claude**：支持Claude 3 Opus、Sonnet、Haiku模型
- 原有支持：OpenAI、Azure OpenAI、阿里云通义千问、智谱AI、百度文心一言、科大讯飞星火

#### 2.2 模型联动功能
- 实现`updateModelOptions()`函数
- 选择不同供应商时，模型下拉列表自动更新对应的可用模型
- API Endpoint自动填充对应供应商的默认地址
- 模型映射关系：
  ```javascript
  {
    'openai': ['gpt-4', 'gpt-4-turbo', 'gpt-3.5-turbo'],
    'minimax': ['abab6-chat', 'abab5.5-chat', 'abab5-chat'],
    'anthropic': ['claude-3-opus', 'claude-3-sonnet', 'claude-3-haiku'],
    // ... 其他供应商
  }
  ```

#### 2.3 界面优化
- 调整了AI配置表单的输入框宽度，使用`flex: 1`自适应
- 优化了textarea的样式，最小高度100px，支持垂直调整
- 统一了配置项的边框和圆角样式

### 3. 项目管理功能增强 ✅

#### 3.1 项目视图切换
- 在项目信息页面顶部增加"当前项目视图"下拉选择器
- 支持在多个项目之间快速切换
- 切换后整个系统所有模块（概览、计划、进展等）将显示该项目数据
- 实现`switchProject()`函数处理项目切换逻辑

#### 3.2 新增项目功能
- 增加"+ 新增项目"按钮
- 复用项目编辑弹窗（`projectModal`）
- 支持创建新项目并自动添加到项目列表

#### 3.3 项目删除功能
- 增加"删除项目"按钮（危险操作，红色按钮）
- 删除项目将同时删除该项目下所有数据
- 需要二次确认以防止误操作

#### 3.4 项目信息优化
- 将项目信息放入边框容器中，提升视觉层次
- 增加项目切换说明，明确切换影响范围
- 增加项目删除的警告提示

### 4. 新增功能预留 ✅

#### 4.1 微信对话维护
- 新增"微信对话"标签页
- 功能预览界面，说明未来功能：
  - 微信扫码登录授权
  - 对话式数据录入（如"新增学校XX"）
  - 对话式数据查询（如"XX学校进度"）
  - 对话式页面更新（如"更新XX模块内容"）
  - 消息记录与审计日志
- 预留"配置微信接入"按钮

#### 4.2 问答机器人
- 新增"问答机器人"标签页
- 功能预览界面，说明未来功能：
  - 项目知识库管理（文档上传、索引构建）
  - 智能问答（基于RAG检索增强生成）
  - 多轮对话上下文理解
  - 答案来源溯源（引用具体文档段落）
  - 问答日志与质量评估
- 预留"配置知识库"按钮

### 5. JavaScript功能完善 ✅

#### 5.1 标签页映射更新
```javascript
const tabMap = {
  'user': 'userTab',
  'school': 'schoolTab',
  'device': 'deviceTab',
  'supplier': 'supplierTab',
  'template': 'templateTab',
  'dict': 'dictTab',

  'ai': 'aiTab',
  'wechat': 'wechatTab',    // 新增
  'qna': 'qnaTab',          // 新增

```

#### 5.2 弹窗控制优化
- `openModal()`: 添加`show`类和flex显示
- `closeModal()`: 移除`show`类并隐藏
- 支持点击弹窗外部关闭

#### 5.3 AI模型联动
- `updateModelOptions()`: 根据供应商动态更新模型选项和endpoint

#### 5.4 项目管理
- `switchProject()`: 处理项目视图切换
- `showAddProject()`: 打开新增项目弹窗

## 技术细节

### CSS变更
1. `.modal`：从`margin: 5% auto`改为`display: flex; align-items: center; justify-content: center;`
2. `.modal.show`：新增显示状态类
3. `.config-item textarea`：新增textarea样式支持
4. `.btn-danger`：已有红色危险按钮样式

### HTML结构变更
1. AI配置部分：增加`id`属性和`onchange`事件
2. 项目信息部分：重构为包含项目切换器的新布局
3. 新增两个功能预留标签页：`wechatTab`和`qnaTab`

### JavaScript变更
1. 新增3个核心函数
2. 更新标签页映射表
3. 优化弹窗控制逻辑

## 兼容性说明
- 保持与V1.0版本的视觉风格一致
- 所有现有功能继续正常工作
- 新增功能均为增量更新，不影响现有业务流程
