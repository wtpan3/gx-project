## 一、页面概述

### 1.1 模块定位

设备台账管理，记录项目所有设备的来源、去向与当前状态。提供多维度视图，支持快速了解硬件交付整体情况。

### 1.2 核心功能

- 设备台账列表（CRUD）
- 多维度分组视图（按学校/产线/系统/状态）
- 顶部统计卡片（与首页环形图数据一致）
- 序列号范围搜索（支持单号匹配范围）
- 批量导入/导出

### 1.3 用户角色权限

| 角色 | 权限 |
|------|------|
| 管理员 | 读写 |
| 项目经理 | 读写 |
| 校园经理 | 读写 |

## 三、顶部统计卡片

### 3.1 布局样式

```
┌──────────────────────────────────────────────────────────────┐
│ [设备总数]  [待发货]  [已到货]  [已安装]  [已调试]  [运行中] │
│   287        45        32        98        67        45      │
│   100%      15.7%     11.1%     34.1%     23.3%     15.7%    │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 数据说明

| 卡片名称 | 数据来源 | 计算规则 |
|---------|---------|---------|
| 设备总数 | 所有记录 | COUNT(*) |
| 待发货 | 当前状态=待发货 | COUNT(当前状态='待发货') |
| 已到货 | 当前状态=已到货 | COUNT(当前状态='已到货') |
| 已安装 | 当前状态=已安装 | COUNT(当前状态='已安装') |
| 已调试 | 当前状态=已调试 | COUNT(当前状态='已调试') |
| 运行中 | 当前状态=运行中 | COUNT(当前状态='运行中') |

### 3.3 交互说明

- 点击任一卡片 → 筛选条件自动填充对应状态 + 列表自动刷新
- 卡片数据实时响应筛选条件变化

## 六、序列号搜索规则

### 6.1 序列号范围格式

| 格式类型 | 示例 | 说明 |
|---------|------|------|
| 单个序列号 | SN12345 | 单台设备 |
| 数字范围 | 1-50 | 1到50号，共50台 |
| 字母数字范围 | A001-A050 | A001到A050 |

### 6.2 搜索匹配逻辑

**场景**：设备按批次录入，序列号为范围（如"1-50"都在KDGX校）。用户想查"40号设备在哪"。

```
用户输入："40"
系统解析：遍历所有序列号范围记录
匹配判断：40 ∈ [1, 50] → 命中
返回结果：序列号范围"1-50"的设备记录，显示所在学校=KDGX
```

**匹配规则**：
1. 精确匹配：输入值 == 记录中的单个序列号
2. 范围匹配：输入值在记录的"起始-结束"区间内
3. 前缀匹配：输入值为序列号的前缀（如"SN"匹配所有SN开头）

### 6.3 录入校验

- 范围格式：必须为"起始-结束"，起始值 < 结束值
- 数字范围：起始和结束都为纯数字
- 字母数字范围：前缀一致，仅数字部分递增

## 十、已确认事项

1. **完成度定义**：分组视图进度条"完成度" = 运行中设备数 ÷ 该组设备总数（仅"运行中"计入完成）。
2. **示例学校名**：原型中 KDGX/168/CX/XZ 仅为示例，未来通过"学校管理"录入实际学校名称。
3. **统计卡片数据接口**：与首页Dashboard"硬件交付进度"环形图共用同一数据接口，保证口径与数值一致。
4. **序列号混合格式**：支持字母数字混合范围（如 A001-A050），前缀一致、数字部分递增。
