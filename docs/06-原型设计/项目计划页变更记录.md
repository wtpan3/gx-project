## 版本历史

### V2.2 - 2026-07-25 实现对齐（原型 → 代码）

本次为**实现与原型对齐**的修订，非原型设计变更。核心是把先前实现错误的右侧抽屉改回原型指定的居中弹窗，并修复层级显示与 Antd 废弃 API。

**修改内容**：

1. **详情交互：Drawer → Modal（主修正）**
   - 原型 V2.2 的 `openDetail()` 打开的是**居中弹窗**（`#detailModal`，代码注释明确写"替代抽屉"），`.drawer` 系列 CSS 是早期抽屉设计的**遗留死代码**，无任何引用。
   - 前端 `ProjectPlan/index.tsx` 先前误实现为右侧 `Drawer`，本次改为居中 `Modal`，字段与底部操作（关闭 / ➕创建子任务 / ✏️编辑当前任务）对齐原型。
   - 移除了不再使用的 `Drawer` import。

2. **任务层级显示 bug 修复**
   - 详情弹窗原写 `L{currentTask.level}`，但后端详情接口 `GET /project-plan/tasks/{id}` **无 `level` 字段**，导致只显示"L"。
   - 改为按 L1-L5 哪一级有值推算层级（取最深一级）：`work_detail_l5→L5`、`work_content_l4→L4`、`task_package_l3→L3`、`sub_phase_l2→L2`、皆空→`L1`。修复后正确显示 L4 等。

3. **Antd 废弃 API 清理（消除控制台警告）**
   - `Card` 的 `bordered={false}` → `variant="borderless"`（4 处）
   - `Statistic` 的 `valueStyle={{...}}` → `styles={{ content: {...} }}`（4 处）
   - 控制台警告归零。

**同步文档更新**：
- 需求文档 `5.5.4/5.5.5/5.5.6/5.5.7/5.5.8`：详情交互全系统统一表述为"详情弹窗（Modal）"，不再用"抽屉/Drawer"；5.5.5 详情页标准改为 Modal 规范。
- 需求文档 `6.2.5B 任务详情弹窗（V2.2 实现）`：新增小节，记录详情弹窗字段清单、任务层级 L1-L5 推算规则、"后端无独立 level 字段"接口约定、底部操作与关闭方式。
- 需求文档术语表、6.12 需求管理模块等处"抽屉"表述一并改为"详情弹窗（Modal）"。

## 测试脚本经验（非产品 bug，供后续 E2E 参考）

`frontend/e2e-test.js` 调试中发现两个易踩的坑：

1. **Modal DOM 类名**：当前 Antd 版本 Modal 的内容容器是 `.ant-modal-container`，**不是**老版本的 `.ant-modal-content`。选择器写错会一直找不到弹窗（但 `.ant-modal-root`/`.ant-modal-wrap` 存在）。
2. **中文按钮文本插空格**：Antd 在两个 CJK 字符间自动插空格，"关闭"按钮实际文本是"关 闭"。精确匹配 `=== '关闭'` 会失败，应先 `replace(/\s/g,'')` 再比较。否则弹窗关不掉，遮罩层会挡住后续所有点击（连锁导致看板 Tab、新增按钮点击失败）。
