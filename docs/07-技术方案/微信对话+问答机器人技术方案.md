## 一、微信对话模块（OpenClaw集成）

### 1.1 功能定位

**内部项目成员通过微信对话维护页面数据**

- 查询我的待办
- 查看学校进度
- 更新任务状态
- 创建待办
- 查询风险

### 1.2 技术架构

```
项目成员微信
    ↓
微信公众号（普通微信，非企业微信）
    ↓
OpenClaw 服务（腾讯云 Lighthouse）
    ↓
成员独立 Agent（workspace 隔离，每人一个）
    ↓
调用 GX 后端 API
    ↓
返回结果 → 微信回复
```

**关键特点**：
- 使用普通微信公众号（用户标识：openid）
- OpenClaw 已处理微信接入层（无需自己写 XML 解析、签名验证）
- 每个成员有独立 Agent（上下文隔离、权限隔离）
- 通过技能（Skill）扩展业务能力

### 1.3 用户绑定流程

```
1. 用户在【系统管理 - 微信对话】生成绑定码（5分钟有效）
   ↓
2. 用户关注微信公众号"ClawBot"
   ↓
3. 发送绑定码（如"BIND123456"）
   ↓
4. 系统验证绑定码 → 关联 openid 与系统用户
   ↓
5. 绑定成功，可以开始对话
```

### 1.4 OpenClaw 技能配置示例

```yaml
# openclaw_skills/gx_project_skills.yaml

skills:
  # 技能1：查询我的待办
  - name: query_my_todos
    description: 查询当前用户的待办事项
    trigger:
      - "查询我的待办"
      - "我的任务"
      - "今天的待办"
    handler: handlers.todos.get_my_todos
    parameters:
      status: 
        type: string
        enum: [pending, in_progress, completed]
        optional: true
  
  # 技能2：查看学校进度
  - name: query_school_progress
    description: 查询指定学校的交付进度
    trigger:
      - "{{school_name}}进度"
      - "查询{{school_name}}"
    handler: handlers.delivery.get_school_progress
    parameters:
      school_name:
        type: string
        required: true
```

## 二、问答机器人模块

### 2.1 功能定位

**页面嵌入式智能问答，支持三种问答模式**

1. **知识库RAG问答**：基于上传的文档回答
2. **项目数据查询**：查询项目实际数据（进度、设备、任务等）
3. **大模型Agent问答**：调用MiniMax Agent进行推理和工具调用

### 2.2 技术架构

```
前端对话组件
    ↓
后端 QnA API
    ↓
问答路由器（判断问题类型）
    ↓
┌─────────────┼─────────────┐
↓             ↓             ↓
知识库检索    项目数据查询    大模型智能体
(RAG)        (SQL)        (MiniMax Agent)
```

### 2.3 问答路由逻辑

```python
class QnARouter:
    """问答路由器 - 决定使用哪种问答方式"""
    
    async def route(self, question: str):
        # 1. 判断是否项目数据查询（关键词匹配）
        if self.is_project_query(question):
            return await ProjectDataQnA.answer(question)
        
        # 2. 检索知识库
        kb_result = await KnowledgeBaseQnA.search(question)
        if kb_result['confidence'] > 0.7:
            return kb_result
        
        # 3. 调用大模型智能体（兜底+复杂推理）
        return await AgentQnA.answer(question)
    
    def is_project_query(self, question: str):
        """判断是否项目数据查询"""
        keywords = ['进度', '学校', '设备', '任务', '风险', '多少', '状态']
        return any(k in question for k in keywords)
```

## 三、数据库表设计

### 3.1 微信对话相关表

#### wechat_user_bindings（微信用户绑定）

```sql
CREATE TABLE wechat_user_bindings (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL COMMENT '系统用户ID',
    wechat_openid VARCHAR(100) NOT NULL UNIQUE COMMENT '微信OpenID',
    nickname VARCHAR(100) COMMENT '微信昵称',
    avatar_url VARCHAR(500) COMMENT '微信头像',
    status ENUM('active', 'inactive') DEFAULT 'active',
    bound_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_interaction_at DATETIME COMMENT '最后交互时间',
    FOREIGN KEY (user_id) REFERENCES users(id),
    INDEX idx_openid (wechat_openid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='微信用户绑定';
```

#### wechat_conversations（微信对话记录）

```sql
CREATE TABLE wechat_conversations (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL COMMENT '用户ID',
    wechat_openid VARCHAR(100) NOT NULL COMMENT '微信OpenID',
    message_type ENUM('text', 'image', 'voice') DEFAULT 'text',
    user_message TEXT COMMENT '用户消息',
    bot_reply TEXT COMMENT '机器人回复',
    intent VARCHAR(50) COMMENT '识别的意图',
    action_result JSON COMMENT '执行结果',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (user_id),
    INDEX idx_openid (wechat_openid),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='微信对话记录';
```

### 3.2 问答机器人相关表

#### knowledge_documents（知识库文档）

```sql
CREATE TABLE knowledge_documents (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL COMMENT '文档标题',
    content LONGTEXT COMMENT '文档内容',
    file_path VARCHAR(500) COMMENT '文件路径',
    category VARCHAR(50) COMMENT '分类',
    tags JSON COMMENT '标签',
    embedding_status ENUM('pending', 'completed', 'failed') DEFAULT 'pending',
    uploaded_by INT COMMENT '上传人',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category (category)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识库文档';
```

#### qna_conversations（问答记录）

```sql
CREATE TABLE qna_conversations (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL COMMENT '用户ID',
    session_id VARCHAR(100) COMMENT '会话ID',
    question TEXT NOT NULL COMMENT '问题',
    answer TEXT COMMENT '答案',
    answer_type ENUM('knowledge_base', 'project_data', 'agent') COMMENT '答案来源',
    sources JSON COMMENT '答案来源文档/数据',
    feedback ENUM('positive', 'negative', 'neutral') COMMENT '用户反馈',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (user_id),
    INDEX idx_session (session_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='问答记录';
```

### 5.2 问答机器人组件（页面右下角悬浮）

```jsx
// frontend/src/components/QnABot/index.jsx

const QnABot = () => {
  const [visible, setVisible] = useState(false);
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');
  
  const sendMessage = async () => {
    const response = await fetch('/api/v1/qna/ask', {
      method: 'POST',
      body: JSON.stringify({ question: input })
    });
    const data = await response.json();
    
    setMessages([
      ...messages,
      { role: 'user', content: input },
      { role: 'assistant', content: data.answer, sources: data.sources }
    ]);
  };
  
  return (
    <>
      {/* 悬浮按钮 */}
      <div className="qna-bot-trigger" onClick={() => setVisible(true)}>
        <MessageOutlined /> 智能助手
      </div>
      
      {/* 对话窗口 */}
      {visible && (
        <div className="qna-bot-panel">
          <div className="messages">
            {messages.map((msg, idx) => (
              <div key={idx} className={`message ${msg.role}`}>
                {msg.content}
                {msg.sources && (
                  <div className="sources">
                    来源：{msg.sources.map(s => s.title || s.table).join(', ')}
                  </div>
                )}
              </div>
            ))}
          </div>
          <input 
            value={input} 
            onChange={e => setInput(e.target.value)}
            onKeyPress={e => e.key === 'Enter' && sendMessage()}
          />
        </div>
      )}
    </>
  );
};
```
