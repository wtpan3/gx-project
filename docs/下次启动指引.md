
## 3️⃣ 关键功能验证清单

### ✅ 新增任务（方案A）
1. 点"+ 新增任务"
2. 父任务下拉框**应该有 35+ 个选项**（带完整路径，如 `交付实施 / 硬件交付 (L2)`）
3. 选一个父任务 → **当前层级**字段自动变为 `"L{父+1}（父任务 L{父}）"`
4. 填任务名（如"测试任务"）+ 责任人 + 计划日期 + 进度（如 50）
5. 保存 → 任务出现在列表，task_code 自动生成 `WBS-AUTO-0002`

### ✅ 进度编辑
1. 列表视图 → 找任意任务
2. 双击"进度"列的数字 → 变成输入框
3. 改成 75 → 回车 → 提示"已保存"
4. 刷新页面 → 进度仍是 75%

### ✅ 删除任务
1. 列表视图 → 操作列有"详情 · 删除"
2. 点删除 → 弹出确认框"确认删除该任务?"
3. 确认 → 提示"已删除" → 任务从列表消失

### ✅ 状态更新不跳顶
1. 甘特图视图 → 拉到页面中间某任务
2. 点状态标签（如"进行中"）→ 弹出浮层
3. 选"已完成" → 状态变化，**页面不跳回顶部**

### ✅ UI 细节
- 左上角显示"项目交付管理系统"
- 列表没有"优先级"列
- 列表进度列只显示数字（如"50%"），不显示进度条
- 所有状态标签没有 ▾ 三角
- 任务名只显示本级（如"设备安装"），不显示面包屑

## 4️⃣ 如果出问题

### parent-options 接口 404
**原因**：后端没加载新代码

**解决**：
1. Ctrl+C 停止后端
2. 删除所有 `__pycache__` 和 `*.pyc`
3. 重新启动 uvicorn

### 新增任务提交报错
**查看浏览器控制台 Network 标签**，找 POST `/project-plan/tasks` 请求：
- 400 错误 → 看响应 detail（通常是必填字段缺失）
- 500 错误 → 看后端终端输出的 Traceback

### 前端白屏/报错
**查看浏览器控制台 Console 标签**：
- `MODULE_NOT_FOUND` → `npm install`
- `Unexpected token` → 语法错误，检查最近改动
