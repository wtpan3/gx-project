### 技术要点

1. **部分更新日期校验陷阱**：行内编辑常只传一个日期字段，必须取库中另一端现值比较，否则只比 payload 内部会漏判
2. **parent_id 双轨制**：存量数据父子关系分散在 parent_id（36个）和 L1-L5 路径字段（73个）两套，校验逻辑走 parent_id，故需回填打通
3. **ORM 外键陷阱**：model 有 source_device_id 指向不存在的 devices 表，ORM commit 触发 NoReferencedTableError，用 `text()` 原生 SQL 绕过
4. **409 vs 400 语义**：越界冲突返409（Conflict，可通过选策略解决），无重叠返400（Bad Request，数据本身有问题无法修复）
